# Корона (ARGB-лента) — лампа в Home Assistant через Zigbee

В Home Assistant появляется устройство из двух сущностей:

- **Свет** — лампа: вкл/выкл, выбор цвета, яркость
- **Эффект** — выбор из списка: Свой цвет, Радуга, Дыхание, Перелив, Огонёк, Мерцание, Ночник (белый 20%), Камин (мерцание выбранным цветом), Волна, Сияние, Полиция

Цвет, яркость и эффект запоминаются и переживают отключение питания.

## Подключение (схема — `korona-esp32h2-schema.svg`)

| Что | Куда |
|---|---|
| Зелёный провод ленты (DATA) | GPIO0 напрямую (3.3 В). Резистор 330 Ом необязателен, только для защиты, см. ниже |
| Красный провод ленты | +12 В (для 5-вольтовой ленты — +5 В) |
| Белый провод ленты | GND, тянуть вместе с DATA с одного разъёма |
| Питание платы | 5 В с DC-DC понижайки и GND |

GND платы, ленты и блока питания общие.

### Кнопки и ИК-приёмник (схема — `korona-controls-pinout.svg`)

| Что | Куда на плате |
|---|---|
| ИК-приёмник, выход (OUT) | **GPIO14** |
| ИК-приёмник, питание (VCC) | **3V3** (не 5 В: выход приёмника тогда был бы 5 В и мог бы повредить пин) |
| ИК-приёмник, GND | GND |
| Кнопка 1 (вкл/выкл) | **GPIO5** — второй контакт на GND |
| Кнопка 2 (цвет / режим) | **GPIO4** — второй контакт на GND |
| Кнопка 3 (яркость) | **GPIO1** — второй контакт на GND |

Кнопки замыкают пин на GND, подтяжку к 3.3 В делает сама плата, внешние резисторы не нужны.

Длину ленты (число адресов; у 12 В ленты один адрес обычно = 3 светодиода) задаёшь с клавиатуры, см. ниже «Настройка длины». Значение запоминается.

## Прошивка

Первая сборка долгая (скачивается Zigbee-стек).

- Через USB-C платы: зажать **BOOT**, воткнуть кабель, отпустить BOOT, Upload. Если после перезагрузки порт сменил номер, смотри диспетчер устройств.
- Монитор порта: 115200, клавиша `?` — справка.

## Добавление в Z2M

1. Положи `korona.js` в `data/external_converters/` Z2M, перезапусти Z2M.
2. **Если плата уже была добавлена со старой прошивкой:** удали её в Z2M (Remove, лучше Force remove).
3. В мониторе порта нажми `X` (сброс сети Zigbee).
4. В Z2M открой **Permit join**, плата подключится сама.
5. Открой устройство → **Reconfigure**.

## Кнопки на корпусе

| Кнопка | Нажатие | Удержание |
|---|---|---|
| **1** | вкл / выкл | 5 с: сброс сети Zigbee (3 мигания и перезагрузка) |
| **2** | следующий цвет из 10 | 3 с: следующий режим, и следующие 3 с каждое нажатие тоже меняет режим; пауза больше 3 с с последней смены — снова цвета |
| **3** | ярче на 1 ступень (всего 7) | 2 с: темнее на 1 ступень, дальше ещё по 1 ступени каждую секунду |

Если выбран режим без своего цвета (радуга, перелив, сияние, полиция, ночник), клик по цвету переключает в «свой цвет».

## ИК-пульт

Кнопки пульта (20 штук): вкл/выкл, AUTO (радуга), SPEED +/- (скорость эффектов, 7 ступеней), MODE +/- (режим вперёд/назад), яркость +/- (7 ступеней, при удержании повторяется), W (ночник), красный, зелёный, синий, жёлтый, оранжевый, фиолетовый, голубой, таймер на 1, 2, 3 и 4 часа (лента сама выключится; индикация: столько миганий, сколько часов). Скорость запоминается, в Home Assistant не уходит. Четыре кнопки с микрофоном не используются.

### Как записать другой пульт

1. Открой монитор порта, нажми `I`.
2. Плата по очереди просит каждую из 20 кнопок. Нажимай её **два раза** (второй раз проверяется на совпадение с первым).
3. В конце плата выведет таблицу кодов и готовый массив `IR_CODES`. Скопируй и вставь в `main.cpp` на место `static uint32_t IR_CODES[N_IR] = { 0 };`.
4. Если пульт не NEC, плата выведет «сырые» длительности импульсов; пришли их, и я добавлю нужный протокол.

Коды твоего пульта (NEC, адрес 0xFF00) уже вписаны в `main.cpp`. Незнакомая кнопка пишет в монитор «kod ... ne naznachen».

## Монитор порта

| Клавиша | Действие |
|---|---|
| `0` | вкл/выкл |
| `1`–`9` | эффект: радуга, дыхание, перелив, огонёк, мерцание, ночник, камин, волна, сияние |
| `p` | эффект 10: полиция |
| `c` | свой цвет (без эффекта) |
| `r` `g` `b` `w` | красный, зелёный, синий, белый |
| `+` `-` | ярче / тише |
| `L` | настройка длины ленты |
| `I` | запись ИК-пульта (`q` — отмена) |
| `S` | статус |
| `X` | сброс сети Zigbee |

## Настройка длины

1. В мониторе порта нажми `L`. Зелёная точка — первый адрес, красная — последний, всё между ними слабо светится белым.
2. Жми `+` (на 1 адрес) или `>` (на 10) — красная точка уезжает вдоль ленты. `-` и `<` двигают назад.
3. Когда красная точка ушла за конец ленты и пропала — вернись на шаг `-`, пока она снова не появится на последнем адресе.
4. Нажми `L` ещё раз — длина сохранится в памяти платы, лента погаснет.

## Если не подключается

Радио выкручено на максимум (20 dBm), роутер без детей (`max_children = 0`), как на ARGB-хабе. Если всё равно не находит сеть: `X`, Permit join, плата рядом с координатором. Если плата ранее была в другой сети — `erase_flash` и прошить заново.

## Если цвета перепутаны

У этой ленты порядок BRG (байты идут синий, красный, зелёный), он уже прописан. Если на другой ленте цвета перепутаны, поменяй порядок в `ledsShow()` (строка `uint8_t col[3]`).
